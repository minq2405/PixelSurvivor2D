# PIXEL SURVIVOR - PROJECT BRIEF

## 1. Project Overview
* **Project Name:** Pixel Survivor
* **Genre:** 2D Fast-Paced Roguelite Action Survivor (Vampire Survivors gameplay + Minecraft Aesthetic)
* **Target Platforms:** PC (Keyboard/Mouse) & Mobile (Touch/Virtual Joystick)
* **Engine & Version:** Unity 6 LTS (6000.4.10f1)
* **Render Pipeline:** Universal Render Pipeline (URP 2D)
* **Input System:** Unity New Input System Package (`InputSystem_Actions`)
* **In-Game Language:** 100% English

## 2. Core Gameplay Loop
1. **Move & Survive:** Player moves in an infinite/tiled 2D map, automatically attacking approaching waves of enemies.
2. **Collect & Level Up:** Defeated enemies drop EXP gems/emeralds. Collecting gems fills the top EXP bar to trigger Level Up modal.
3. **Choose Upgrades:** Select 1 of 3 randomized weapon/passive upgrade cards (2-click selection mechanism).
4. **Boss Encounters & Extraction:** Survive escalating enemy density until timed Boss spawns. Defeating bosses unlocks new characters/realms.

## 3. Playable Characters
* **Steve:** Balanced melee warrior (Starts with Flaming Broadsword).
* **Alex:** High agility ranged scout (Starts with Rapid Bow).
* **Villager:** High luck / economy specialist (Bonus emeralds, starts with Emerald Toss).
